## CHASSIS_TASK 切到 squat_torque2（25 维单帧 / 125 维历史）—— 19:10

训练侧权威来源：`D:/IsaacLab-main/infantry_rl_s2r/`
- `docs/squat_torque_onnx_usage.md`、`exports/chassis_squat_torque2.json`
- `mdp/observations.py::proprio_obs`、`mdp/actions.py::FiveBarJointAction`

关键事实（从 ONNX 实测确认）：
- 网络输入 **不是 25 维，是 125 维**（5 帧 × 25，oldest→newest）；Slice starts=[-25] 取最后一帧当 current，
  encoder(125→128→64→3) 出 latent，Concat 28 → actor → 6 维 action。
- 归一化 (history-mean)/denom 已烧进 ONNX（mean/denom 各 125 个数），固件送原始值。
- 单帧 25 维：ang_vel(0:3)×0.25 / gravity(3:6) / command(6:9)=0 / hip-LOCKED(9:13) /
  joint_vel(13:19)×0.05 / last_action(19:25)。
- **矛盾点**：`proprio_obs()` 里 joint_vel 用 ×0.05，但 sidecar json 与 `tools/export_policy_onnx.py`
  写的是 0.1（导出脚本注释没同步）。以训练代码 0.05 为准，需用 golden vector 复核。
- 动作：a=clip(±4)；q_ref = SQUAT_HIPS + a[0:4]×0.5（再 clamp URDF 限位）；
  tau_hip = clamp(40(q_ref-q) - 1·qdot, ±40)；v_ref = a[4:6]×10；tau_whl = clamp(0.5(v_ref-qdot), ±3.69)。
- LOCKED_HIPS = SQUAT_HIPS = [-0.011721, +0.0118, +0.011721, -0.0118]（HIP_ORDER = lf,lb,rf,rb）。

已改 `Task/src/CHASSIS_TASK.c`（整份重写，编译通过，FLASH 324244 B / RAM_D1 82284 B）：
- 100 Hz 控制步（原 50 Hz），DWT 分频；1 kHz 外层循环保留 osDelay(1)。
- 125 维历史用 memmove 维护；上电首帧用当前帧填满 5 帧。
- 髋 PD 在固件算，阻尼用 DM 内部 vel（`chassis_hip_vel_pd`），观测用位置差分（与训练一致）。
- 下发：`app_dm_cmd_mit(&dm_motor_data[i], 0,0,0,0, sign*tau)`；轮子走 C620 电流，
  Kt_eff = 0.246 × 19.203 × 0.85（原代码直接用 0.246 是转子侧值，会小 19 倍）。
- 删掉了 fivebar_forward_kinematics / imu_odom 以外的旧 42 维逻辑；fivebar 现已无人调用
