## 核心结论（详见报告）

- 阶段 A 前 100 → 末 100 轮：平均回报 −135.4 → +115.8，回合长度 890.6 → 984.7 / 1000 步，超时率 89.6% → 97.5%；
  日志速度误差 1.147 → 0.139（真实平均误差约 0.069 m/s，日志值约为真实值 2 倍）。
- 阶段 A 第 470–570 轮出现一次“从站着不动到走起来”的能力跃迁（姿态失控率一度 31%，随后回落）。
- **速度范围**：两段训练与后续计划均使用**仅前进** `vx ∈ [+0.2, +1.2] m/s`（不含负速度/倒车），另有 10% 站立（vx = 0）样本；训练代码默认值已从 v1.0.10 的 `[−1.2, +1.2]` 回退为 `+0.2`，并保留 `REL_STANDING_ENVS = 0.1`（见 `isaac_ws/isaac_ws_infantry/tasks/locomotion/locomotion_env_cfg.py`）。
- 阶段 B 续训 124 轮内保持稳定：末 100 轮平均回报 161.1、回合长度 985.1、误差 0.1306 / 0.3081，
  相比阶段 A 末段误差约 −5.8% / −4.0%，但训练量不足以判定精度项收敛；阶段 B 因中断未保存最终策略。
- 已知问题：阶段 B（及后续 `2026-10-22_15-22-23`）的 `pitch` 奖励权重为 `−0.0` —— **已确认是代码笔误**（`weight=-.0`，漏了 `4`），已于 v1.0.24 修复为 `−4.0`；日志误差为真实值 2 倍；
  VERSION.md 部分环境变量默认值滞后于代码；单卡 8 GB 下 PhysX 周期性崩溃需靠检查点续训（详见附录 C）。
